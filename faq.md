# FAQ

## General

**Q: What is PVZRH Launcher?**
A: A BepInEx loader for Plants vs Zombies Fusion on Android. It enables modding support by injecting the BepInEx framework into the game process.

**Q: Does this work with the original Plants vs Zombies?**
A: No, this launcher is specifically designed for Plants vs Zombies Fusion.

**Q: Do I need root?**
A: No, root is not required.

**Q: Is it safe?**
A: The app is fully open source. Review the code at [GitHub](https://github.com/ModPVZRH/PVZRH.Android.Launcher).

## Mods

**Q: Where do I put mod files?**
A: Create or open a modpack, then tap Add Mod to select .dll files.

**Q: Can I use multiple mods at once?**
A: Yes, add multiple .dll files to the same modpack.

**Q: My mod doesn't work, what should I check?**
A: Verify the mod version matches your game version, check the BepInEx log for errors, and ensure the mod is compatible with Android/IL2CPP.

## Troubleshooting

**Q: The game crashes on startup.**
A: Try disabling Unstripped libunity, clearing libunity cache, or clearing BepInEx files.

**Q: How do I report a bug?**
A: Export logs from the crash dialog or log viewer and share them on [GitHub Discussions](https://github.com/ModPVZRH/PVZRH.Launcher-release/discussions).
