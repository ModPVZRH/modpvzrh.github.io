# Quick Start

## First Launch Onboarding

When you open the launcher for the first time, a 6-page onboarding guide will walk you through the setup:

1. **Welcome** — Overview of what the launcher does
2. **Game Detection** — Scans for installed Plants vs. Zombies: Fusion
3. **File Access Permission** — Grants storage access needed for mod injection
4. **First Launch** — Explains that the first start may download files
5. **Crash Logs** — Shows how to share logs when something goes wrong
6. **Troubleshooting** — What to do if the game crashes (clear BepInEx/libunity data)

You can tap **Skip** to exit early or **Later** on pages 1–2. The guide can be replayed anytime from **Settings → Onboarding Guide**.

## Launch with No Mods (Vanilla)

1. Open PVZRH Launcher
2. Wait for game detection to complete
3. Tap **Launch**

The game will start with BepInEx loaded but no mods installed.

## Launch with Mods

1. Go to the **Modpacks** tab
2. Create a new modpack or select an existing one
3. Tap **Activate**
4. Go back to the **Games** tab
5. Tap **Launch**

The active modpack will be applied automatically.
