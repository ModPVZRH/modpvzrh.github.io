# Installation

## Requirements

- Android 7.0 or higher
- [Plants vs Zombies Fusion](https://github.com/ModPVZRH) installed on your device

## Steps

1. Download the latest APK from [GitHub Releases](https://github.com/ModPVZRH/PVZRH.Launcher-release/releases)
2. Open the APK file and install it
3. When prompted, grant **All files access** permission
4. The launcher will automatically scan for Plants vs Zombies Fusion

## Storage Permission

PVZRH Launcher needs access to all files to:
- Extract BepInEx framework files
- Manage mod files and modpacks
- Copy game data for modding support
