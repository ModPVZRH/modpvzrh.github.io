# Troubleshooting

## Game won't launch

- Ensure Plants vs Zombies Fusion is installed
- Check that storage permission is granted
- Try clearing BepInEx files in Settings → Maintenance

## Mods not loading

- Verify .dll files are in the correct modpack
- Check BepInEx log for error messages
- Ensure the mod is compatible with the game version
- Try clearing .NET data and re-extracting

## Crash on startup

- Disable **Use Unstripped libunity** in Settings if enabled
- Clear libunity cache in Settings → Maintenance
- Export crash logs and share with developers

## Black screen on second launch

This was a known issue in earlier versions. Update to the latest release.

## BepInEx extraction fails

- Ensure you have enough storage space
- Try clearing BepInEx files and letting it re-extract
- Check launcher log for specific error messages
