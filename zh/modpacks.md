# 整合包管理

## 创建整合包

1. 进入**整合包**标签页
2. 点击**创建整合包**
3. 输入名称并确认
4. 整合包已创建，可以添加模组

## 添加模组

1. 打开你的整合包
2. 点击**添加模组**
3. 从设备中选择 .dll 模组文件
4. 模组将被复制到整合包中

## 激活整合包

1. 从列表中选择一个整合包
2. 点击**激活**
3. 启动器将其标记为当前激活的整合包
4. 启动游戏 — 激活的整合包将自动应用

同一时间只能激活一个整合包。激活新的整合包会自动停用之前的。

## 导入/导出

### 导出
1. 打开你的整合包
2. 点击**导出**
3. 通过分享发送 .zip 文件给朋友

### 导入
1. 进入**整合包**标签页
2. 点击**导入整合包**
3. 选择 .zip 文件
4. 整合包及其所有模组将被导入

## 浏览模组文件

1. 打开你的整合包
2. 点击**浏览模组文件**
3. 查看整合包中的所有文件和目录
4. 点击文件可查看或编辑
