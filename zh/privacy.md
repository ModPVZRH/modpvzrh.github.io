# 隐私政策

**生效日期：** 2026年8月29日

PVZRH Launcher（"我们"）运营 PVZRH Launcher Android 应用程序。本隐私政策说明您使用该应用时如何处理个人数据。

## 1. 数据控制者

**PVZRH Mod Dev**
GitHub: https://github.com/ModPVZRH

## 2. 收集的数据

### 2.1 您提供的数据
本应用不收集任何个人信息。无需用户账户、无需登录，也不会向任何服务器传输个人数据。

### 2.2 自动收集的数据
本应用**不会**收集：
- 分析或跟踪数据
- 广告标识符
- 用于遥测的设备信息
- 通过第三方服务收集的崩溃报告

### 2.3 本地存储的数据
以下数据仅存储在您的设备上：
- BepInEx 日志（用于模组调试）
- 游戏配置文件
- 整合包文件和设置
- 崩溃日志（仅在检测到崩溃时生成）

这些数据均不会自动上传或传输到任何地方。

## 3. 第三方服务

### GitHub
应用通过 GitHub API 检查更新。这可能会将您的 IP 地址和应用版本传输给 GitHub。参见 [GitHub 隐私政策](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)。

### gh-proxy.org
当启用"使用未剥离的 libunity"选项时，应用通过 gh-proxy.org 下载文件。这可能会将您的 IP 地址传输给代理服务。

## 4. 数据存储
所有数据均存储在您的设备上。不执行云同步或远程数据存储。

## 5. 数据保留
本地数据会保留到您通过应用设置手动删除或卸载应用为止。

## 6. 儿童隐私
本应用面向 13 岁及以上用户。我们不会故意收集 13 岁以下儿童的个人数据。

## 7. 政策变更
我们可能会不时更新本隐私政策。变更将发布在此页面上，并附有更新的生效日期。
