# PVZRH Launcher 文档

## 简介

PVZRH Launcher 是一个用于 Android 版植物大战僵尸融合版的 BepInEx 加载器。它通过将 BepInEx 框架注入游戏进程来启用模组支持。

## 安装

1. 从 [GitHub Releases](https://github.com/HayashiUme/PVZRH.Android.Launcher/releases) 下载最新 APK
2. 在您的 Android 设备上安装 APK
3. 出现提示时授予"所有文件访问"权限
4. 启动器将自动扫描植物大战僵尸融合版

## 快速开始

1. 打开 PVZRH Launcher
2. 等待游戏检测完成
3. 点击 **启动** 以通过 BepInEx 启动游戏
4. 要使用模组，请先创建或激活整合包

## 整合包管理

### 创建整合包
1. 进入 **整合包** 标签页
2. 点击 **创建整合包**
3. 输入名称并确认
4. 将 .dll 模组文件添加到整合包中

### 激活整合包
1. 从列表中选择一个整合包
2. 点击 **激活**
3. 启动游戏 — 活动的整合包将被应用

### 导入/导出
- 导出：将整合包共享为 .zip 文件
- 导入：从 .zip 文件加载整合包

## 设置

| 设置项 | 描述 |
|--------|------|
| 主题 | 深色 / 浅色 / 系统默认 |
| 语言 | English / 简体中文 / 系统默认 |
| 使用未剥离的 libunity | 下载并使用带有完整 icalls 的未剥离 libunity.so |
| 浮动日志 | 在游戏中显示浮动日志按钮 |

## 崩溃检测

当游戏崩溃时，启动器会显示一个对话框，包含：
- 崩溃信号（如果可用）
- 崩溃日志的片段
- 导出完整日志的选项

导出的日志通过系统分享菜单分享。

## 日志查看器

从启动器的日志界面访问 BepInEx 日志：
- 按以下方式筛选：全部 / 错误 / 警告
- 自动滚动切换
- 复制或分享日志内容

## 故障排除

### 游戏无法启动
- 确保已安装植物大战僵尸融合版
- 检查是否已授予存储权限
- 尝试在设置中清除 BepInEx 文件

### 模组未加载
- 验证 .dll 文件是否在正确的整合包中
- 检查 BepInEx 日志中的错误
- 确保模组与游戏版本兼容

### 启动时崩溃
- 如果已启用，请禁用"使用未剥离的 libunity"
- 在设置中清除 libunity 缓存
- 导出崩溃日志并分享给开发者

## 常见问题

**问：这适用于原版 PVZ 吗？**
答：不适用，此启动器专为植物大战僵尸融合版设计。

**问：我需要 root 吗？**
答：不需要，无需 root 权限。

**问：安全吗？**
答：此应用完全开源。您可以在 [GitHub](https://github.com/HayashiUme/PVZRH.Android.Launcher) 上查看代码。
