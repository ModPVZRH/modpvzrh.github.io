# 故障排查

## 游戏无法启动

- 确认设备上已安装**植物大战僵尸融合版**
- 检查是否已授予启动器**存储权限**
- 尝试在**设置 → 维护 → 清除 BepInEx 文件**中清除 BepInEx 文件
- 如果游戏立即崩溃，请查看**日志查看器**中的错误详情

## 模组未加载

- 确认 `.dll` 文件在正确的整合包目录中
- 检查 **BepInEx/LogOutput.log** 中的错误信息
- 确认模组与当前游戏版本兼容
- 尝试在**设置 → 维护**中清除 `.NET` 数据并重新解压

## 启动时崩溃

- 如果启用了"使用未剥离的 libunity"，请在设置中关闭
- 在**设置 → 维护 → 清除 libunity 缓存**中清除缓存
- 通过崩溃对话框的**导出日志**功能导出崩溃日志并分享给开发者
- 检查设备是否有足够的可用内存

## 二次启动黑屏

这是早期版本的已知问题，由 `UnityPlayer.kill()` 终止启动器进程导致。请更新到最新版本，新版本已 hook 该 kill 调用并延迟执行以允许正确清理。

## BepInEx 解压失败

- 确保存储空间充足（至少 500 MB 可用）
- 尝试清除 BepInEx 文件后在下次启动时重新解压
- 检查启动器日志中的具体错误信息
- 如果下载速度慢，请尝试使用 VPN 或代理

## libunity 下载缓慢

未剥离的 libunity 库托管在 GitHub Releases 上。如果在您的地区下载缓慢，请在网络设置中启用 VPN 或代理。

## 应用显示"检测到运行时错误"

这表示 `:game` 进程意外退出。点击**导出日志**保存诊断信息，然后将导出的文件分享给开发者进行调查。

## 如何导出日志

1. 打开启动器
2. 在主页面点击**导出日志**
3. 选择保存位置
4. 将导出的 `.zip` 文件通过 GitHub Issues 分享给开发者

## 整合包冲突

- 如果遇到问题，一次只启用一个整合包
- 检查模组 DLL 是否依赖冲突的库
- 尝试在**设置 → 维护**中重置到原版状态

## 启动器打开时崩溃

- 在 Android 设置 → 应用 → PVZRH Launcher → 存储 → 清除数据
- 重新安装启动器
- 检查是否运行的是受支持的 Android 版本（API 26+）

## 存档数据访问（Android 12+）

在 Android 12 及以上版本，启动器使用 **Shizuku** 访问游戏存档数据。如果看到安装 Shizuku 的提示：

1. 从 Play Store 或 GitHub 安装 [Shizuku](https://shizuku.rikka.app/)
2. 打开 Shizuku 并启动（按照应用内说明操作）
3. 启动器提示时授予权限

**为什么需要？**
Android 12+ 限制了存储访问框架（SAF）持久访问 `Android/data` 目录的能力。Shizuku 提供 shell 级别的访问权限，可在所有 Android 版本上可靠工作。

**Shizuku 无法启动？**
- 确保开发者选项中已启用 USB 调试
- 部分设备启用开发者选项后可能需要重启
- 中国品牌设备（小米、华为、OPPO、Vivo）可能有额外限制——请查阅 Shizuku 文档了解设备特定说明
