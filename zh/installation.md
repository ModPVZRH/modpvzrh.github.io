# 安装

## 要求

- Android 7.0 或更高版本
- 设备上已安装[植物大战僵尸融合版](https://github.com/ModPVZRH)

## 步骤

1. 从 [GitHub Releases](https://github.com/ModPVZRH/PVZRH.Launcher-release/releases) 下载最新 APK
2. 打开 APK 文件并安装
3. 按提示授予**所有文件访问**权限
4. 启动器将自动扫描植物大战僵尸融合版

## 存储权限

PVZRH Launcher 需要访问所有文件以：
- 解压 BepInEx 框架文件
- 管理模组文件和整合包
- 复制游戏数据以支持模组运行
