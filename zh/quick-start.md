# 快速开始

## 首次启动引导

首次打开启动器时，会出现 6 页引导流程：

1. **欢迎** — 启动器功能概览
2. **游戏检测** — 扫描已安装的植物大战僵尸：融合版
3. **文件访问权限** — 授予模组注入所需的存储权限
4. **首次启动** — 说明首次启动可能需要下载文件
5. **崩溃日志** — 出现问题时如何分享日志
6. **问题排查** — 游戏崩溃时的解决方法（清除 BepInEx/libunity 数据）

可随时点击 **跳过** 提前退出，或在第 1-2 页点击 **稍后**。引导可随时在 **设置 → 新手指南** 中重新播放。

## 无模组启动（原版）

1. 打开 PVZRH Launcher
2. 等待游戏检测完成
3. 点击**启动**

游戏将以加载了 BepInEx 但未安装模组的状态启动。

## 带模组启动

1. 进入**整合包**标签页
2. 创建新整合包或选择已有整合包
3. 点击**激活**
4. 返回**游戏**标签页
5. 点击**启动**

激活的整合包将自动应用。
