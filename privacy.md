# Privacy Policy

**Effective Date:** August 29, 2026

PVZRH Launcher ("we", "our", or "us") operates the PVZRH Launcher Android application. This Privacy Policy explains how personal data is processed when you use the app.

## 1. Data Controller

**Modded-PVZRH/**
GitHub: https://github.com/ModPVZRH

## 2. What Data Is Collected

### 2.1 Data You Provide
The app does not collect any personal information. There are no user accounts, no sign-in required, and no personal data is transmitted to any server.

### 2.2 Automatically Collected Data
The app does NOT collect:
- Analytics or tracking data
- Advertising identifiers
- Device information for telemetry
- Crash reports via third-party services

### 2.3 Data Stored Locally
The following data is stored locally on your device only:
- BepInEx logs (for mod debugging)
- Game configuration files
- Modpack files and settings
- Crash logs (generated only when a crash is detected)

None of this data is automatically uploaded or transmitted anywhere.

## 3. Third-Party Services

### GitHub
The app checks for updates by querying the GitHub API. This may transmit your IP address and app version to GitHub. See [GitHub Privacy Policy](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

### gh-proxy.org
When the "Use Unstripped libunity" option is enabled, the app downloads files through gh-proxy.org. This may transmit your IP address to the proxy service.

## 4. Data Storage
All data is stored locally on your device. No cloud synchronization or remote data storage is performed.

## 5. Data Retention
Local data is retained until you manually delete it through the app's settings or uninstall the application.

## 6. Children's Privacy
The app is intended for users aged 13 and older. We do not knowingly collect personal data from children under 13.

## 7. Changes to This Policy
We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated effective date.
