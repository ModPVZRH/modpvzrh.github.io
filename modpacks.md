# Modpack Management

## Creating a Modpack

1. Go to the **Modpacks** tab
2. Tap **Create Modpack**
3. Enter a name and confirm
4. The modpack is created and ready for mods

## Adding Mods

1. Open your modpack
2. Tap **Add Mod**
3. Select .dll mod files from your device
4. The mods will be copied into the modpack

## Activating a Modpack

1. Select a modpack from the list
2. Tap **Activate**
3. The launcher marks it as the active modpack
4. Launch the game — the active modpack will be applied

Only one modpack can be active at a time. Activating a new one deactivates the previous.

## Import/Export

### Export
1. Open your modpack
2. Tap **Export**
3. Share the .zip file with friends

### Import
1. Go to the **Modpacks** tab
2. Tap **Import Modpack**
3. Select a .zip file
4. The modpack will be imported with all its mods

## Desktop Shortcut

You can create a desktop shortcut for quick access to a modpack.

1. Open your modpack
2. Toggle **Create Shortcut** on
3. A shortcut will be created on your home screen
4. Tap the shortcut to launch the game directly with that modpack

> **Note:** Some Chinese OEM devices (Xiaomi, Huawei, OPPO, Vivo) require you to manually grant shortcut permission in system settings.

## Editing Modpack Icon

You can customize the icon for each modpack.

1. Open your modpack
2. Tap the modpack icon
3. Select an image from your device
4. The icon will be saved and displayed on the modpack list and shortcut

## Browsing Mod Files

1. Open your modpack
2. Tap **Browse Mod Files**
3. View all files and directories in the modpack
4. Tap a file to view or edit it
